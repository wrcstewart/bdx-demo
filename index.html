A media module, lifted out of ButterflyDreaming.

BDX · AVX · RX — a controller, a viewer and a relay

ButterflyDreaming (BD) is a collaborative arts‑therapy and peer‑counselling system: a corpus of literature, art and music that anonymous users collage together in conversation.

BDX is one of its media modules, taken out and made to stand on its own — a controller, a viewer and a relay, with no database, no corpus and no accounts behind them. Two web pages and a script. It is here so that anyone can play with a typical module, and so that a developer can work on the part they actually care about: what you build runs independently, and goes back into BD unchanged.

Open the controller

See it. The drawing is based on kolams, grown from an L‑system. Edit the script or move a stepper: two ways of saying the same thing. The script is what is true, and everything else is a view of it.

Developer information

Two different mechanisms, and which one you need depends only on where the viewer is.

postMessage is a browser API, not a network one: one window handing a message to another on the same machine. The drawing is an iframe driven that way, and a controller that opened its viewer can drive it the same way — about a millisecond, with no server involved at all.

WebSockets are for the other case. Two devices have no window handle between them, so something must stand in the middle: the relay, which holds a WebSocket to each side and passes messages between them. (Socket.IO, so it opens on long‑polling and upgrades.) For simplicity BDX uses the relay even for a viewer on the same machine, but nothing in the architecture requires that — and the relay is substitutable.

Build on it. The renderer is replaceable. Anything that takes a script by postMessage and announces what it drew can stand in its place. BDX is the harness: it shows what a host must provide, and how little that is.

A relay is live behind this copy, so the demo works on click. To run the whole thing yourself: npm install && npm start, then http://localhost:8081/bdx.html. To point these pages at a relay of your own, ?rx=https://your-relay — no forking required, and remembered for that browser afterwards.
